# Face Invaders

A Space Invaders–style browser game where the invaders are faces from the office.

Play: https://titantomorrow.github.io/face-invaders/

- Keyboard: ← → or A/D to move, Space to fire, P or Esc to pause
- Touch (iPad/phone): drag on the game to move and fire, or use the ◀ FIRE ▶ buttons

Everything is in a single `index.html` — no build step.
